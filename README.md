# cooolinho.de

Personal portfolio website with a terminal-styled interface, built with Vite and SCSS.

## Getting started

```bash
npm install
npm run dev
```

Open the URL shown by Vite (default: `http://localhost:5173`).

## Commands

| Command          | Description                  |
| ---------------- | ---------------------------- |
| `npm run dev`    | Start the dev server         |
| `npm run build`  | Build the site into `/dist`  |
| `npm run preview`| Preview the production build |

## Project structure

```
cooolinho.de/
├── index.html        # Main page (terminal layout)
├── package.json      # Scripts & dependencies (Vite, Sass)
├── vite.config.js
└── src/
    ├── main.js       # Typing animation, smooth scroll
    └── style.scss    # Styles (SCSS, terminal theme)
```

## Tech stack

- [Vite](https://vitejs.dev/)
- [SCSS](https://sass-lang.com/)
